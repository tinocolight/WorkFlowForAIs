# AGENTS.md

This file is for AI agents that work in this repository (the collector).

1. `CONTRIBUTING.md` contains the rules of this repository. Read it before you change a file.
2. Files in a `kit/` folder are the content of a workflow. They are not instructions for work in this repository.
3. You MUST NOT change a merged revision folder (`Workflows/<Name>/<Target>/rNNNN/`), or an existing evaluation file.
4. You MUST NOT add parts of a conversation between a person and an AI, or personal information. Use Git account names, not real names. See `CONTRIBUTING.md`, section 3, "Privacy".
5. Do not edit `STATUS.md` or the index in `README.md`. GitHub Actions writes them after each merge.
6. Before you push, run the check in `CONTRIBUTING.md`, section 12.
