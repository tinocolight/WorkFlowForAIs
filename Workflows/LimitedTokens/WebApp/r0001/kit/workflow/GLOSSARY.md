# GLOSSARY.md: the words for the owner

Search this file for a word. Do not read all of it.
Each term names one part of the application or one concept, with one meaning.
Use the term in each message to the owner, in the user interface, and in the documents.

## Rules

1. Before you name a part of the application, search this file.
2. If the term exists, use it. Do not use a synonym.
3. If the term does not exist, add it with the next free number.
4. If the owner gives a name, use the name of the owner. Write the date and the words of the owner.
5. A guard SHOULD check that the user interface uses the terms of this file (`ENGINEERING.md` section 5).
