# LimitedTokens workflow for web applications

## Scope of the evidence

The owner tested this workflow on two web applications only. Both applications are in construction now.

1. **Acervo**: a personal catalog application. The Markdown files of the method started in this project.
2. **Consonância**: a tool that creates prototypes of calm, coherent mobile applications. The tool shows each prototype in a simulated application named Drwamium. The method files moved from Acervo to Consonância.

Consonância is a single HTML file with no server and no third-party dependencies.
On 2026-10-10, three AI contributors and one tester branch worked on Consonância in parallel.
The method had recorded stages 0 to 48.

Revision 0001 is a general copy of the method as Consonância used it on 2026-10-10.
The names and the rules that are specific to Consonância are not in the revision.

## Revisions

`STATUS.md` lists each revision with its base, its verdict, and its role. A program writes it after each merge.
Revisions r0001 and r0002 are from before October 2026: they have no "Based on" line, so each one is based on the previous number.

## Evaluations

Each project that uses a Closed revision adds a file to `Evaluations/` (`CONTRIBUTING.md`, section 8).
`STATUS.md` is the summary of the evaluations. A program generates it.
